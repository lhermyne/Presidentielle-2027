# Présidentielle 2027

Projet autonome : aucun import, secret ou chemin d'exécution vers PatriBot.
Respecter BRIEF.md et DESIGN.md. Frontend React / React Router / JavaScript / Tailwind.
La production est exclusivement statique sur GitHub Pages. La collecte Python et les
calculs Node s'exécutent dans GitHub Actions. Aucun serveur permanent, Docker ou Caddy.
Ne jamais inventer de sondage, résultat, historique ou candidature officielle.
Séparer strictement les configurations de candidats. Une donnée absente n'est pas zéro.
Les paramètres initiaux sont expérimentaux, non calibrés. Ne pas prétendre à une
validation historique sans backtest documenté. Conserver les dates et attributions.
Vérifier le modèle avec npm test et python -m unittest discover -s tests -p "test_*.py".
Vérifier le build et les interactions sur ordinateur, tablette et mobile.
